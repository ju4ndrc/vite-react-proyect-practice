
# ⚡ Vite + React Practice Project

A lightweight practice project using **Vite** and **React** to explore modern frontend development: ultra-fast dev server, hot module replacement (HMR), component-driven UI, and clean project structure. Ideal for learning, experimenting, and bootstrapping small apps.

---

## ✨ Features

- 🚀 **Vite** dev server with instant HMR  
- ⚛️ **React 18** with functional components and hooks

## 🧱 Tech Stack

- **React 18**
